# AMIN Legal Model

مشروع مستقل لتطوير نموذج ذكاء اصطناعي متخصص في القانون المصري.

## الهدف
بناء مساعد قانوني متخصص لتحليل الوقائع والمستندات والأدلة، وتحديد المسائل القانونية والدفوع والردود المحتملة، والمساعدة في الصياغة القانونية باللغة العربية.

## المبادئ
- المشروع مستقل عن تطبيق «المساعد أمين» الحالي ولا يغيّر ملفاته أو إعداداته.
- لا ندّعي تدريب نموذج أو امتلاك أوزان مخصصة قبل تنفيذ ذلك والتحقق منه.
- يمنع اختلاق نصوص القوانين أو الأحكام أو أرقام الطعون أو الوقائع أو الاقتباسات.
- تُربط الاستنتاجات بالمصادر المتاحة، وتُظهر النواقص ودرجات عدم اليقين.
- تُحمى بيانات الموكلين ولا تُستخدم في التدريب دون أساس قانوني وموافقة مناسبة.
- تُراجع تراخيص النماذج والبيانات قبل أي استخدام، خصوصًا الاستخدام التجاري.

## مراحل التطوير
1. تأسيس بنية المشروع والاختبارات.
2. مقارنة النماذج المفتوحة والتحقق من التراخيص ومتطلبات التشغيل.
3. وضع سياسة لجمع وتنظيف وتوثيق البيانات القانونية.
4. إعداد مجموعة تقييم قانونية مصرية واختبارات منع الهلوسة.
5. بناء واجهة استدلال API قابلة للتشغيل على خادم مناسب.
6. إجراء تقييم عملي قبل أي ربط بالتطبيق الأصلي.

## الحالة الحالية
المستودع في مرحلة التأسيس. لم يُعتمد نموذج أساسي نهائيًا، ولم يبدأ تدريب مخصص أو نشر خدمة استدلال إنتاجية.

## تنبيه
لا ترفع مستندات قضايا حقيقية أو بيانات شخصية أو مفاتيح API أو أسرار تشغيلية إلى هذا المستودع.
