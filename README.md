# AMIN Legal Model

مشروع مستقل لبناء محرك ذكاء اصطناعي قانوني متخصص في **كل فروع القانون المصري**، مع دعم التحليل والبحث والصياغة والتفكير الاستراتيجي للمحامي. المستودع مستقل عن تطبيق «المساعد أمين» ولا يغيّر ملفاته أو إعداداته.

## ما أصبح موجودًا في المستودع

- API مبني على FastAPI: فحص الصحة، الاستجابة القانونية، وفرز القرار الاستراتيجي الأولي.
- واجهة Provider قابلة للتبديل، مع مشغل محلي اختياري لـ Hugging Face Transformers؛ تحميل النموذج كسول، والتنزيل الشبكي متوقف افتراضيًا.
- تعليمات أساسية للمحامي المصري: تحديد مركز الموكل، بناء التسلسل الزمني، اختبار أقوى حجة للخصم، تقييم توقيت الرد ومخاطر الصمت، وعدم اختلاق النصوص أو الأحكام.
- مستورد Offline لمستندات TXT/MD/HTML/PDF/DOCX والصور، مع حراسة صلاحيات المصدر.
- OCR اختياري للصور وصفحات PDF المصورة باستخدام Tesseract، مع تحديد الصفحة ودرجة الثقة وفرض المراجعة البشرية.
- فهرس بحث نصي عربي/إنجليزي أولي باستخدام SQLite FTS5، مع حفظ مرجع المصدر وإعادة فحص صلاحية الاسترجاع.
- روابط زمنية مسجلة للتعديلات والإلغاءات وتصفية أولية حسب تاريخ السريان.
- اختبارات آلية عبر GitHub Actions.

## التثبيت والتشغيل

الأساس والاختبارات:

\`\`\`bash
pip install -e ".[dev]"
pytest
uvicorn amin_legal_model.api:app --host 127.0.0.1 --port 8000
\`\`\`

للاستيراد PDF/DOCX:

\`\`\`bash
pip install -e ".[documents]"
\`\`\`

للـ OCR:

\`\`\`bash
pip install -e ".[documents,ocr]"
\`\`\`

ويجب تثبيت برنامج Tesseract وملفات اللغة العربية والإنجليزية \`ara\` و\`eng\` على الخادم نفسه. التفاصيل في [دليل OCR](docs/OCR_INGESTION.md).

لتشغيل نموذج محلي بعد مراجعة ترخيص checkpoint وتجهيزه على الخادم:

\`\`\`bash
pip install -e ".[inference]"
\`\`\`

ثم تعيين \`AMIN_MODEL_ID\` إلى مسار النموذج المحلي. لا يوجد checkpoint معتمد أو أوزان نموذج مخصصة مضمّنة في المستودع حاليًا. راجع [دليل تشغيل النموذج](docs/MODEL_RUNTIME.md).

## نقاط API الأساسية

- \`GET /health\`
- \`POST /v1/legal/strategy\` — فرز شفاف أولي للرد أو عدم الرد ومخاطر الميعاد والصمت. ليس توقعًا للحكم ولا بديلًا عن مراجعة المحامي.
- \`POST /v1/legal/respond\` — يستدعي النموذج المهيأ. يمكن تمرير \`retrieval_query\` و\`as_of_date\` لاسترجاع مقتطفات من فهرس مصرح به؛ يعيد المراجع في \`sources\` والتحذيرات في \`warnings\`.

في بيئة الإنتاج اضبط \`AMIN_ENV=production\` و\`AMIN_API_KEY\`؛ تُحمى مسارات \`/v1\` بمفتاح \`X-Amin-Api-Key\`. ما زالت هناك حاجة إلى rate limiting على مستوى البوابة/الخادم، ومراقبة وسجلات آمنة قبل الإطلاق العام.

## ما لا ندّعي اكتماله

**هذا ليس بعد إصدارًا قانونيًا إنتاجيًا مكتمل المعرفة أو نموذجًا مصريًا مدربًا.** خريطة التغطية تحدد نطاق جميع الفروع، لكنها ليست قاعدة بيانات قوانين وأحكام مكتملة. سجل التراخيص مغلق افتراضيًا ولا يسمح بجمع أي مصدر دون إذن موثق. لا يوجد حتى الآن corpus مصري شامل ومراجع أو موافقات استخدام تجاري نهائية أو checkpoint مختار ومقاس أو تدريب مخصص. كما أن البحث الحالي نصي FTS5 وليس بحثًا دلاليًا، وتتبع التعديلات يعتمد على صحة البيانات الوصفية ولا يدمج نصوص المواد المعدلة تلقائيًا.

لا يجوز الاعتماد العملي على نتيجة قانونية قبل مطابقة النص النافذ والأحكام من مصادرها الرسمية ومراجعة محامٍ. لا ترفع ملفات قضايا حقيقية أو بيانات شخصية أو مفاتيح وأسرار إلى المستودع.
