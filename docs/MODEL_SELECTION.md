# Model selection criteria

No base model is selected yet. Candidate evaluation must include:

- Arabic and Egyptian legal-language quality.
- Reasoning over long documents and mixed evidence.
- Context length and reliable structured output.
- Inference speed, GPU memory, hosting cost, and scaling.
- Model weights, tokenizer, code, and dataset license compatibility.
- Commercial-use, redistribution, and fine-tuning permissions.
- Reproducibility, security, and maintenance status.

A candidate must pass a documented benchmark before adoption. A model name alone is not evidence of suitability.
